# app_flutter

Flutter app (Android + iOS) with the Dart engine.

## Setup (Dev B)
Install Flutter, then from this folder:
```
flutter create . --org et.gebeta --project-name gebeta_app
flutter pub get
flutter test
```
Planned packages: flame, flutter_riverpod, hive, flame_audio, intl.
The Dart engine must pass `../tests/test_cases.json`.
